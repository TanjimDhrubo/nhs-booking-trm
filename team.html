Behind the build

About This Project

The Brief

This NHS Appointment Booking System was developed as a group university project. The brief required a fully functional web application allowing patients to register, book appointments, check in, and manage their medical appointments online.

The Challenge

We were tasked with replacing a traditional PHP and MySQL stack with modern alternatives. We chose Supabase for our cloud database and authentication, and built the entire frontend with vanilla JavaScript and semantic HTML5 — no frameworks, no shortcuts.

Tech Stack

Frontend HTML5, CSS3, Vanilla JS
Database Supabase PostgreSQL
Authentication Supabase Auth (JWT)
Security Row Level Security (RLS)
Hosting GitHub Pages
Version Control Git & GitHub
